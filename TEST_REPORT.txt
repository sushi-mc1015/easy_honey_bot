HTTP型ハニーボット テスト仕様及び実行結果レポート

記入者: 宮川 惺
記入日: 7/24

テスト目的----------------------------------------------
honeyserver.pyが正常に起動し、HTTPリクエストへの応答と
アクセスログの記録が正しく行われることを確認する。
起動画面にURLが表示されることを確認する。

テスト仕様と結果----------------------------------------------
テスト項目: サーバー起動
実施手順:
  1 python3 honeyserver.pyを実行する。
期待結果:
  「*** START HTTP HONEYBOT ***」とURLが表示される。
実施結果:
  成功
確認内容:
  127.0.0.1:18080で正常に起動した。

テスト項目: GETリクエスト
実施手順:
  1 ブラウザでhttp://127.0.0.1:18080/を開く。
期待結果:
  管理者ログイン画面が表示される。
実施結果:
  成功
確認内容:
  User ID、Password、Loginボタンが表示された。

テスト項目: POSTログイン入力
実施手順:
  1 User IDへtest_studentを入力する。
  2 Passwordへqwerty1234を入力する。
  3 Loginを押す。
期待結果:
  403 Forbiddenとなり、Login Failedが表示される。
実施結果:
  成功
確認内容:
  入力内容に関係なくログイン失敗画面が表示された。

テスト項目: 認証情報ログ
実施手順:
  1 T03の後、logs/access.logを開く。
期待結果:
  接続元、ユーザー名、パスワード、パスが記録される。
実施結果:
  成功
確認内容:
  user='test_student' password='qwerty1234'が記録された。

テスト項目: 存在しないURL
実施手順:
  1 http://127.0.0.1:18080/adminを開く。
期待結果:
  404 Not Foundが返され、アクセスがログに記録される。
実施結果:
  成功
確認内容:
  404画面とUnknown pathログを確認した。

テスト項目: 自動テストクライアント
実施手順:
  1 サーバー起動中にpython3 test/test_client.pyを実行する。
期待結果:
  GET status: 200
  login form: True
  POST status: 403
  failed page: True
実施結果:
  成功
確認内容:
  4項目すべて期待値と一致した。

テスト項目: サーバー停止
実施手順:
  1 サーバー画面でCtrl+Cを押す。
期待結果:
  Shutdown...と表示され、プログラムが終了する。
実施結果:
  成功
確認内容:
  KeyboardInterruptを受けて正常終了した。

テスト結果まとめ----------------------------------------------
全7項目を実施し、すべて予想した結果となった。
getではログイン画面を表示し、POSTでは入力された認証情報を記録した後、
必ずLogin Failedを返すことを確認した。

セキュリティ上の注意
・127.0.0.1でのみ待ち受ける設定にした。
・実際のOSコマンドやファイル操作は行わない。
・入力データの長さを4096バイトまでに制限した。

結論----------------------------------------------
本プログラムは、授業で学んだHTTPサーバー、文字列処理、
UTF-8のencode/decode、loggingを組み合わせたハニーボットとして
正常に動作した。
